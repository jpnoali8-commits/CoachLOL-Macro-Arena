# Plano de marcos pós-v2.9

**P1 gameplay:** aplicar efeitos individuais de todos os kits Q/W/E/R, cooldowns/restrições de rank, combos, buffs direcionados; monstros/torres/super-minions e objetivos com resolução justa.

**P1 apresentação:** recursos oficiais do catálogo por patch e fallback offline, ícones de summoner spells/itens completos, animações de interação discretas, mover/redimensionar/salvar layout dos docks.

**P2 produto:** login, salas, servidor autoritativo, multiplayer, replay de turnos, anti-cheat, MMR/PDL/ranked após balanceamento.
